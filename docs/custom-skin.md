# 导入自己的桌面形象

Vesper Board 的桌面形象就是一个文件夹里的一组 PNG。自己画（或让 AI 生成）之后，
在 **设置 → 形象 → 导入形象…** 里选这个文件夹就行，程序会把它复制到用户目录，
以后升级、重装都不会丢。

## 放哪儿

```
%LOCALAPPDATA%\VesperBoard\pet\<你的形象名>\
```

导入之后也可以直接往这里放文件夹，重启程序即可看到。

## 画布与格式

| 项目 | 要求 |
|---|---|
| 尺寸 | **512 × 512**，建议 PNG-32（带透明通道） |
| 背景 | **透明**；如果只有纯色底，请给成品图，不要给带边框/卡片的截图 |
| 脚底位置 | 脚底贴 **y = 496**（离画布底边 16 px） |
| 头部高度 | **约 400 px**（从头顶到下巴），四个角色并排时头部才会等高 |
| 身体位置 | 水平居中 |
| 比例 | 建议 2～2.5 头身，和「小西」「小贝塔」放在一起不违和 |

## 文件命名

一个状态一张 PNG，文件名必须是小写的这些：

| 文件 | 什么时候显示 |
|---|---|
| `idle.png` | **必需**，待机 |
| `hover.png` | 鼠标悬停在人物上 |
| `syncing.png` | 正在刷新数据 |
| `class.png` | 正在上课 |
| `urgent.png` | 有 24 小时内到期 / 已逾期的作业 |
| `done.png` | 全部交完 |
| `error.png` | 登录失效 / 网络断开 |

缺哪一张就用 `idle.png` 顶上，所以最少只要一张 `idle.png` 就能用。

## 生成时的小提示

- 让模型一次出「同一角色的七种表情/动作」，数值写死：*正面全身、脚底对齐、
  头顶到脚 470 px、纯透明或纯品红背景（#FF00FF）、无文字无水印*。
- 品红底可以用 `tools/paper_to_sprite.py` 抠成透明：
  ```bash
  python -I tools/paper_to_sprite.py 输入.png 输出目录/idle.png
  ```
- 多人一张的表可以先按空白列切分，再逐张归一化到「头高 400、脚底 496」。

## 检查清单

1. 打开图片，背景是**灰白格子**（透明），不是白色实底。
2. 脚底在同一条线上，切换状态时人物不会上下跳。
3. 头顶到下巴约 400 px，七个状态一致。
4. 文件名小写，和上表一致。

满足之后导入，形象列表最后一组会出现你的角色，点一下即可切换。
